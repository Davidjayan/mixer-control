The user's ear decides. Keep the master where they set it and don't raise it unless asked. They often move faders themselves in the same browser window during a session, so read current values and build on their changes rather than overwriting them.

Be honest about what was actually changed or measured. They check the mixer screen and challenge claims, such as asking why choir sends had not changed. They prefer plain explanations and short summaries.

**Why:** they corrected the mix by ear several times (choir too loud, then too low), and asked for values to be tested rather than assumed.

**How to apply:** report what the screen will show and which tab to open. Explain any calculated number that is not on screen. If a result is unproven, say so. Related: [[church-audio-engineer-role]].
